# 🖨️ Kobra S1 Print Doctor (Powered by Gemma 4)

An open-source, multimodal 3D printing troubleshooting assistant built for **Hacklab Mikkeli** during **Hacktoberfest**. 

Using **Gemma 4**'s native multimodal vision via **Google Cloud Vertex AI** (or Google AI Studio), this tool inspects photos of 3D prints alongside **Anycubic Kobra S1 & ACE Pro** slicer parameters to diagnose defects (stringing, warping, heat creep, layer shifts) and prescribe exact slicer fixes.
